SHINYU's iPhone — fan-made fictional simulation

How to open on a computer:
1. Extract the ZIP file.
2. Double-click index.html.
3. It should open in Chrome, Edge, Safari or Firefox.
4. Click the lock-screen button to unlock.
5. Click app icons; click the bottom bar to return home.

To share with an iPhone over the internet, upload index.html to a static website host of your choice. The local file is not a public website.

Notes: This is an early functional prototype. Official app icons and real TWS public photos are NOT included yet. The Weverse, IG, X and chat content is fictional demonstration data. Notes, chats, comments and likes are stored locally in the browser.
